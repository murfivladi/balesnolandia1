# ВлодБраузер для iOS — интервью

Ответы владельца проекта (52 вопроса). Это основа будущего ТЗ нативного приложения.

## Платформа и раздача
1. Устройства: iPhone и iPad.
2. Первая раздача — Swift Playgrounds (проект `.swiftpm`). Swift Playgrounds есть только на iPad и Mac, поэтому iPhone ждёт TestFlight.
3. Mac нет, только iPad: собираем и запускаем в Swift Playgrounds на iPad.
4. Минимальная версия — iOS 17 (SwiftUI, `@Observable`, SwiftData).
5. В будущем App Store — скрыто, только по ссылке (unlisted).
6. Код — в папке `ios/` этого репозитория.
7. Проект на iPad забирают со страницы `/ios/` сайта игры: она публичная, с кнопкой «Скачать .swiftpm» и инструкцией для Swift Playgrounds.
8. Обновления: баннер «Доступна новая версия», приложение сверяет свою версию с сервером.
9. Если не собирается: и CI на macOS-раннере GitHub Actions (сборка под симулятор iOS), и скриншоты ошибок в чат.
10. Иконку рисуем сами в стиле иконки PWA.
11. Отчёты о сбоях — свои, на VPS, видны в админке. Сторонних сервисов нет.
12. Менять API ради приложения можно (новые эндпоинты с миграциями и тестами).

## Объём и вид
13. Браузер плюс нативные добавки: все сайты в WKWebView, а QR, Face ID, кошелёк, уведомления, терминал, DevTools сделаны нативно.
14. Название на домашнем экране — «ВлодБраузер».
15. Язык — только русский.
16. Стиль — как Chrome для iOS (как веб-ВлодБраузер).
17. Адресная строка на iPhone — сверху или снизу, на выбор в настройках.
18. Вкладки на iPhone — сетка карточек с миниатюрами, свайп закрывает вкладку.
19. На iPad — полоса вкладок сверху, как в десктопном Chrome.
20. Тема по умолчанию системная, есть ручной переключатель; тема передаётся сайтам.
21. Новая вкладка: поиск ВлодПоиска, часто посещаемые сайты и госсайты, лента БалНовостей (`novosti.bln`, уже есть), обои и настройка.

## Сеть
22. Сервер жёстко задан: `vps.vladislavb.qzz.io`, сменить нельзя.
23. При первом запуске выбирают провайдера, как будто заключают договор (БалТелеком / ВлодЛинк / Балесно-Мобайл), потом вход.
24. Игровой статус-бар «Балесно-Мобайл» показывает:
    1. имя провайдера и «сигнал» по пингу до VPS;
    2. IP БалНета (по нажатию);
    3. игровую дату и время;
    4. тариф и трафик.
25. Тариф связи — абонплата за игровой месяц автоплатежом, трафик не ограничен.
26. Цены тарифов задают и админ (госоператоры), и игроки-провайдеры с лицензией, по образцу хостеров.
27. Открывается только БалНет: несуществующий домен даёт ошибку DNS БалНета, настоящий интернет недоступен.
28. Госсайты (`bank.bln`, `gosuslugi.gov.bln`, `kassa.bln`…) открываются по адресу `*.bln` так же, как в веб-ВлодБраузере.
29. Нет связи или техработы: игровая страница ошибки с мини-игрой (как `game.jsx` в вебе).

## Аккаунт, безопасность, приватность
30. Вход — через сайт ВлодУслуг в WebView, cookie сохраняется в приложении.
31. Face ID спрашивается в трёх случаях:
    1. при открытии `bank.bln`;
    2. перед переводом или оплатой;
    3. вместо ввода PIN карты.
32. Профили — как в вебе: у каждого свои вкладки, история, cookies и IP.
33. Инкогнито — как в Chrome: отдельные вкладки, ничего не сохраняется, временный IP.
34. Изоляция: у госсайтов своё хранилище, сайты игроков живут в песочнице шлюза и банк не видят.
35. Приватность банка:
    1. размытие экрана при сворачивании;
    2. предупреждение при скриншоте банка.
36. Родительский контроль — детский профиль с лимитом часов в день и запретом после заданного времени. Снимается по PIN родителя в приложении.

## Данные
37. История, закладки, вкладки синхронизируются через аккаунт ВлодБраузера, с веб-версией тоже. Аккаунт с шифрованием уже есть (Н8.2).
38. Синхронизируются закладки, история, открытые вкладки, пароли и настройки.
39. Менеджер паролей хранит данные в Keychain под Face ID и синхронизируется в зашифрованном виде.
40. Загрузки (чеки PNG, паспорт, выписки) можно:
    1. отправить через меню «Поделиться»;
    2. сохранить в «Фото»;
    3. сохранить в «Файлы»;
    4. найти на экране «Скачанные».
41. Импорт из веб-ВлодБраузера двумя способами: по QR и файлом JSON.

## Нативные функции
42. QR-сканер:
    1. оплата по QR;
    2. проверка паспорта, чека или документа;
    3. адреса сайтов;
    4. штрихкоды для Кассы.
43. Уведомления:
    1. переводы и оплаты;
    2. квитанции, счета и долги;
    3. заявления, домены и хостинг;
    4. Web Push сайтов.

    Локальные работают, пока приложение запущено. Настоящие пуши APNs появятся с Apple Developer.
44. Web Push сайтов — один API для iOS и веб-ВлодБраузера (`push.bln` уже есть, Н10).
45. Виджеты не нужны.
46. Кошелёк свой, нативный: карты с QR и штрихкодом для кассы. Apple Wallet не нужен.
47. Оплата между устройствами — QR на экране.
48. Интеграции с iOS:
    1. Siri и Команды;
    2. вибрация и звуки;
    3. быстрые действия с иконки;
    4. ссылки `bln://` из других приложений.
49. Расширения браузера будут позже, отдельным этапом.

## Касса
50. Режимы на iPad:
    1. касса во весь экран без браузера;
    2. терминал покупателя;
    3. киоск и табло очереди с подсказкой включить «Гид-доступ».
51. Печать чеков 58 мм — через AirPrint и меню «Поделиться».

## Для сайтостроителей и поиск
52. Терминал `balnet://terminal` — нативный экран с панелью клавиш (Tab, ↑, Ctrl).
53. DevTools полные: Network, консоль, элементы (DOM), хранилище (cookies, localStorage).
54. Нативно:
    1. просмотр кода страницы;
    2. SSH-клиент для хостинга;
    3. редактор файлов хостинга.
55. ВлодПоиск:
    1. красный экран Safe Browsing;
    2. подсказки в адресной строке;
    3. реклама на новой вкладке.

## Первая версия (И1)
Браузер: вкладки, адресная строка, история, lease/open, WKWebView, госсайты. К этому терминал и DevTools.

## Ограничения Swift Playgrounds, которые учитываем
- На iPhone нет Swift Playgrounds, поэтому iPhone ждёт TestFlight с Apple Developer.
- Виджеты, расширения приложения и APNs недоступны (виджеты и не нужны). URL-схема `bln://`, App Intents (Siri) и Face ID в `.swiftpm` есть, но их надо проверить на устройстве.
