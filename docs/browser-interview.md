# ВлодСеть — интервью (браузер, интернет, DNS, хостинг, поиск)

Ответы владельца проекта. Это основа будущего ТЗ.

## Общее
1. Формат: симуляция в вебе (вымышленный интернет внутри страницы).
2. Аудитория: друзья.
3. Платформа: веб.
4. Домены: только вымышленные.
5. Строим поверх текущего репозитория.
6. Сайты делаются «как в реальном интернете, без упрощений».
7. Аккаунты: у каждого сайта своя регистрация, как в реальном интернете.
8. ВлодБанк, ВлодУслуги, Касса станут сайтами внутри сети.
9. Домены и хостинг платные во влодиках.
10. Зонами управляют организации, назначенные админом, и сам админ (не ИП).
11. Сайты: статика HTML/CSS/JS, серверный код, визуальный конструктор, своя CMS.

## Сеть
12. DNS: полная иерархия (корень, TLD, авторитетные NS, рекурсивные резолверы, кэш, TTL).
13. Свои IP-адреса, ping/traceroute.
14. Хостинг-провайдер — любой игрок с государственной лицензией.
15. HTTPS: свои CA, полная система, желательно реальная криптография.

## Поиск и сервисы
16. Один официальный поисковик.
17. Краулер по ссылкам (robots.txt, sitemap), PageRank/SEO, платная реклама, кабинет вебмастера.
18. Сразу: маркетплейс, новости, вики.
19. Базовые сервисы делаем мы, остальное — игроки.

## Браузер
20. Выглядит как Chrome.
21. Вкладки, история, закладки, DevTools, cookies и пароли, расширения.
22. Изоляция сайтов: один домен (⚠ риск для ВлодБанка — нужен отдельный разбор защиты).
23. Серверный код: несколько языков.

## Хостинг и домены
24. Тарифы: статический, виртуальный.
25. Неуплата — как в реальности (отключение, льготный период, освобождение домена).
26. Передача доменов, аукцион, WHOIS, споры.
27. Зоны: .bln, .gov.bln, .edu.bln, .vlod, .shop, .com; остальные админ создаёт в админке.
29. В браузер входят анонимно.
30. Оплата на сайтах — эквайринг ВлодБанка (API, вебхуки).
31. НДС с онлайн-продаж.

## Модерация и безопасность
32. Реестр запрещённых сайтов, abuse-жалобы, фильтр реального вредного контента, игровой VPN.
33. Взлом сайтов — часть игры + bug bounty (взлом настоящего сервера запрещён).

## Инфраструктура
34. До 20 человек.
35. VPS слабый (1–2 ГБ RAM).
36. Языки серверного кода через WASM (без Docker).
37. Файлы сайтов на диске VPS.
38. Сеть замкнутая, без выхода в реальный интернет.
39. Порядок: браузер → DNS → хостинг → поиск.

## Названия и адреса
40. Браузер — ВлодБраузер. 41. Сеть — БалНет. 42. Поисковик — ВлодПоиск.
43. bank.bln, gosuslugi.gov.bln, kassa.bln.
44. Админка остаётся снаружи БалНета.
45. Прямые адреса /bank/, /pos/ и т. д. сохраняются (касса, терминал, киоск на планшетах).
46. Стартовая: строка ВлодПоиска, плитки сайтов, новости и курсы, реклама.
47. Своя мини-игра на офлайн-странице, коды ошибок, терминал (ping, nslookup, dig, traceroute, whois, curl).

## Хостинг (детали)
48. Лицензия хостера — заявление в ВлодУслугах (ИП, госпошлина, одобрение, срок).
49. Хостер арендует мощности у государства или дата-центра и перепродаёт их.
50. БД сайтов: SQLite на сайт + key-value.
51. Деплой: файловый менеджер с редактором, игровой FTP/SSH, игровой Git, ZIP.

## Сертификаты и безопасность
52. Бесплатный авто-CA (90 дней), платный OV/EV, самоподписанные с предупреждением.
53. Настоящие подписи ECDSA, браузер проверяет цепочку через WebCrypto.
54. Игровой фишинг разрешён; настоящий вход защищён значком браузера.
55. Сайты игроков — iframe sandbox без allow-same-origin, cookies эмулирует браузер.

## Поиск (детали)
56. Картинки, новости, товары, подсказки и тренды.
57. Аукцион за клики + рекламная сеть на сайтах игроков с долей владельцу.
58. ВлодПоиском владеет государство.
59. Краулер работает по приоритету + кнопка «переобойти».

## Сервисы (детали)
60. Маркетплейс: витрина всех Касс + объявления.
61. Новости: админ, СМИ игроков (RSS), автособытия, ИИ-журналист.
62. Вики с модераторами.
63. Нужны почта, соцсеть, мессенджер.
64. Почта: полная симуляция (MX, SPF, DKIM, DMARC, спам, свои почтовые серверы).
65. На настоящий email — только уведомления.
66. Соцсеть: лента и друзья.
67. Мессенджер: личные и групповые чаты, каналы, боты, переводы денег.
68. Названия сервисов придумываем мы.
69. Расширения пишут игроки на JS, манифест с правами.
70. VPN — решаем сами.
71. Провайдеры бесплатные.
72. Несколько провайдеров от админа, выбор в настройках.
73. DNS-сервер можно указать вручную.
74. A, AAAA, CNAME, MX, TXT, NS, SOA, SRV, CAA, DNSSEC.
75. Офлайн-игру придумываем мы.
76. Конструктор: блоки + правка кода.
77. CMS: блог, интернет-магазин, форум, плагины и темы.
78. Серверные языки через WASM: JavaScript (QuickJS), Python (Pyodide), PHP (php-wasm).
79. Лимиты тарифов реальные (диск, запросы, CPU).
80. SSH — эмуляция shell (выбрали мы: лёгкая для VPS).
81. Игровой Git: репозитории, деплой по push, issues и PR, настоящий git clone.
82. DevTools: Elements, Console, Network, Application, Sources.
83. Своя аналитика сайтов.

## Организации, модерация, право
