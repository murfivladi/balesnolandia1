# БалНет и ВлодБраузер — ТЗ и план этапов

Черновик для согласования. Основа — интервью из 150 вопросов (`docs/browser-interview.md`).

> Игровой сервис. Все домены, IP-адреса, сертификаты и деньги вымышленные. Сеть замкнута и в реальный интернет не выходит.

## 1. Цель

Вымышленный интернет Балесноландской Федерации — **БалНет**, который открывается в браузере **ВлодБраузер** (внешне как Chrome). В нём всё устроено как в настоящем интернете, без упрощений: IP-адреса, DNS с полной иерархией, регистраторы и реестры, хостинги, CA и HTTPS с настоящими подписями, поисковик с краулером, почта с SPF/DKIM. Друзья делают в нём свои сайты и бизнесы, учатся настоящим веб-технологиям и играют в экономику БФ.

Красные линии:
1. Старые приложения (банк, Касса, Услуги, админка) не ломаются никогда.
2. Данные не теряются.
3. Сеть не упрощается.
4. Расходы не выходят за бюджет: ИИ — до $5 в месяц, VPS — нынешний на 1–2 ГБ.

## 3. Архитектура

Стек прежний: React + Vite (новое приложение `web/browser/`), Fastify + MySQL (`api/src/routes/net/*`, `api/src/lib/net/*`), общие модули в `shared/`.

### 3.1 Как открывается страница

1. Пользователь вводит `https://shop.vasya.bln/catalog`.
2. Оболочка браузера резолвит имя через выбранный DNS-резолвер (провайдера, введённый вручную или игровой). Запрос идёт по настоящей цепочке: корень → TLD `.bln` → авторитетный NS домена → A-запись. Ответ кэшируется с учётом TTL. Всё видно в DevTools → Network.
3. Оболочка получает IP, связывается с «сервером» по этому IP через шлюз API (`/_net/…`). Шлюз определяет, какой хостинг держит этот IP, и отдаёт ответ.
4. Для HTTPS шлюз возвращает цепочку сертификатов. Оболочка проверяет подписи ECDSA через WebCrypto, срок действия (в игровых месяцах), отзыв и CAA. Результат — замок или ошибка `ERR_CERT_*`.
5. Ответ показывается в `iframe sandbox="allow-scripts allow-forms allow-popups allow-modals"` **без allow-same-origin**. Код сайтов игроков не может прочитать cookies, localStorage или API ВлодБанка, хотя всё работает на одном реальном домене (решение по вопросам 22 и 55).
6. В страницу встраивается прослойка (shim): `fetch`, `XMLHttpRequest`, `WebSocket`, `document.cookie`, `localStorage` и `location` подменяются и работают через `postMessage` с оболочкой. Оболочка применяет к ним правила БалНета: DNS, CORS, cookies по доменам БалНета, Same-Origin по доменам БалНета.

Госсайты (bank.bln, gosuslugi.gov.bln, kassa.bln) — доверенные: это существующие приложения на реальном origin. Они получают особый значок «Проверенный госсайт БФ», который нельзя подделать: его рисует оболочка, а не страница. Так фишинговая копия в игре возможна, а настоящий вход всегда видно (вопрос 54).

> Важно. Service Worker не может перехватывать запросы из sandbox-iframe с непрозрачным origin, поэтому вся сеть идёт через shim и шлюз, а не через SW. SW остаётся только для PWA и офлайн-страницы.

### 3.2 Сетевой уровень

- Адресное пространство БалНета: вымышленные блоки IPv4 и IPv6, которые выдаёт админ. Провайдерам выдаются блоки для пользователей, дата-центрам — блоки для серверов.
- Провайдеры (несколько, от админа, бесплатные): каждый выдаёт IP, свой рекурсивный резолвер и свой список блокировок.
- Утилиты в терминале браузера: `ping`, `traceroute`, `nslookup`, `dig`, `whois`, `curl`. Маршрут для traceroute вычисляется по топологии «провайдер → магистраль → дата-центр».

### 3.3 DNS

- Полная иерархия: корневые серверы → TLD → авторитетные NS → рекурсивные резолверы с кэшем и TTL.
- Записи: A, AAAA, CNAME, MX, TXT, NS, SOA, SRV, CAA, DNSSEC (DNSKEY, DS, RRSIG на настоящем ECDSA P-256).
- Игроки могут держать зону у регистратора, у хостера или **на своём DNS-сервере** — скрипте на виртуальном тарифе с обработчиком `onDnsQuery`.
- Резолвер можно указать вручную. Отсюда настоящие DNS-атаки как часть игры: подставной резолвер, отравление кэша чужого резолвера игрока, перехват просроченного домена.

### 3.4 Время

Все денежные и юридические сроки считаются в игровых месяцах: домен — 12, сертификат — 3, тарифы — помесячно, льготный период — 1. TTL и кэш тоже считаются по игровым часам: в одном игровом месяце `game_month_minutes` реальных минут. В игровом месяце 30 игровых суток, поэтому при игровом месяце в 10 реальных минут игровой час длится около 0,8 реальной секунды и кэш DNS почти не заметен. Чтобы кэш и TTL ощущались, админ ставит игровой месяц длиннее (например, сутки). Во время паузы игрового времени весь БалНет показывает «БалНет на обслуживании».

## 4. Участники и лицензии

Новые сущности (нужны и для этапов 8–9):
- **Юрлица** (ООО/АО): учредители, директор, счёт во ВлодБанке.
- **Госучреждения**: создаёт админ, назначает сотрудников.

Лицензии выдаются через заявление во ВлодУслугах: госпошлина, одобрение, срок в игровых месяцах.

| Роль | Кто | Что делает |
| --- | --- | --- |
| Реестр зоны | Госучреждение или организация, назначенная админом | Держит TLD, задаёт оптовую цену |
| Регистратор | Лицензированная организация | Продаёт домены с наценкой, WHOIS, передача |
| Хостер | Игрок или организация с лицензией | Арендует мощности у госдата-центра, продаёт тарифы |
| CA | Гос-CA и лицензированные CA | Выпускают сертификаты. Админ ведёт список доверенных корней |
| Провайдер | Назначается админом | IP, резолвер, блокировки |
| Азарт | Лицензия, игроки 18+ по паспорту БФ | Казино и лотереи |

Зоны на старте: `.bln`, `.gov.bln`, `.edu.bln`, `.vlod`, `.shop`, `.com`. Новые создаёт админ.

## 5. Домены

- Цена = опт реестра + наценка регистратора. Обе растут с индексом инфляции.
- Жизненный цикл как в реальности: активен → истёк (сайт перестаёт открываться) → льготный период → восстановление за плату → освобождение → домен можно перехватить или он уходит на аукцион.
- Передача между игроками по коду авторизации. Аукцион. Публичный WHOIS со скрытием данных. Споры о доменах (до этапа 8 их решает админ, потом суд).

## 6. Хостинг

Тарифы с реальными лимитами (диск в МБ, запросы в минуту, CPU-мс на запрос, соединения WebSocket):
- **Статический**: файлы.
- **Виртуальный**: серверный код, SQLite на каждый сайт и key-value, WebSocket, cron по игровому времени, свои DNS- и SMTP-серверы скриптами.

Серверные языки работают через WASM на VPS, без Docker:
- JavaScript — QuickJS (основной, лёгкий);
- PHP — php-wasm;
- Python — Pyodide. Он тяжёлый (десятки МБ на экземпляр), поэтому один общий пул, очередь и жёсткий лимит одновременных запросов. На 1–2 ГБ RAM Python будет медленным, это ожидаемо.

Деплой: файловый менеджер с редактором кода, загрузка ZIP, эмуляция shell по SSH (`ls`, `cd`, `cat`, `nano`, запуск скриптов), ВлодХаб с настоящим `git clone` по HTTP, деплоем по push, issues и PR.

Файлы сайтов лежат на диске VPS (`/var/balnet/sites/<id>/`). Бэкапы двух уровней: игровой (платная услуга хостера, без неё сайт можно потерять) и системный (ночной, для админа).

Неуплата тарифа: сайт отключается → льготный период → данные удаляются (системный бэкап остаётся).

Аналитика для владельцев: посещения, источники, запросы из ВлодПоиска.

## 7. HTTPS и CA

- Ключи ECDSA P-256. Сертификат — подписанная JSON-структура в духе X.509: subject, SAN, issuer, сроки, расширения. Цепочка корень → промежуточный → лист. Проверка в браузере через WebCrypto.
- Автоматический бесплатный CA (как Let's Encrypt): проверка HTTP-01 или DNS-01, 3 игровых месяца, автопродление.
- Платные OV и EV с проверкой ИП или юрлица — название компании отображается в замке.
- Самоподписанные сертификаты — с предупреждением на весь экран.
- Отзыв сертификата (аналог OCSP), запись CAA, Certificate Transparency — публичный журнал выпущенных сертификатов.
- Страницы ошибок как в Chrome: `ERR_CERT_DATE_INVALID`, `ERR_CERT_AUTHORITY_INVALID`, `ERR_CERT_COMMON_NAME_INVALID`, `ERR_CERT_REVOKED`, `DNS_PROBE_FINISHED_NXDOMAIN`, `ERR_CONNECTION_REFUSED`, `ERR_NAME_RESOLUTION_FAILED` и т. д.

## 8. ВлодБраузер

Внешне как Chrome на компьютере и мобильный Chrome на телефоне. Только русский язык (у старых приложений остаётся it).

- Вкладки, история, закладки, инкогнито, несколько профилей.
- Аккаунт браузера на ВлодПочте: синхронизация закладок, истории и паролей (пароли зашифрованы ещё в браузере). Данные лежат в IndexedDB.
- Cookies и менеджер паролей по доменам БалНета.
- DevTools: Elements, Console, Network (DNS, TLS, заголовки, тайминги), Application (cookies, storage, сертификаты), Sources.
- Расширения: пишут игроки на JS, у каждого манифест с правами. Магазин с модерацией, продажи с комиссией и НДС. Расширения видят только сайты БалНета.
- Push-уведомления с запросом разрешения + настоящий Web Push на телефон.
- Safe Browsing: список фишинга от ВлодПоиска, красная страница «Опасный сайт».
- Стартовая страница: строка ВлодПоиска, плитки сайтов, новости, курсы и инфляция, реклама.
- Офлайн-страница со своей мини-игрой про Балесноландию.
- Настройки: провайдер, DNS-сервер вручную, VPN.

## 9. ВлодПоиск (государственный)

- Краулер ходит по ссылкам с учётом robots.txt и sitemap. Приоритет у популярных сайтов, в кабинете вебмастера есть кнопка «переобойти».
- Ранжирование: PageRank + текстовая релевантность (BM25) + свежесть.
- Вертикали: веб, картинки, новости, товары (из Касс и БалБазара), подсказки и тренды.
- Реклама: аукцион за клики по ключевым словам, дневной бюджет, статистика. Рекламная сеть ставит баннеры на сайтах игроков, владелец сайта получает долю. Доход идёт в госбюджет.
- Кабинет вебмастера: индексация, ошибки, запросы, подтверждение прав через TXT.
- ИИ-ответ над выдачей: несколько бесплатных в день, дальше за влодики.

## 10. Базовые сервисы

- **ВлодПочта**: полная симуляция с MX, SPF, DKIM (настоящие подписи), DMARC и спам-фильтром. Игроки могут держать свою почту на домене или свой SMTP-скрипт. На настоящий email приходит только уведомление «новое письмо в БалНете».
- **ВлодКнига**: профили, друзья, лента, лайки, комментарии, группы.
- **Влодограм**: личные и групповые чаты, каналы, боты через API, переводы влодиков прямо в чате.
- **БалБазар**: витрина товаров всех Касс с онлайн-заказом плюс объявления игроков.
- **Влодипедия**: правки проходят модерацию, есть история правок.
- **Новости**: госновости от админа, СМИ игроков (агрегатор RSS), автособытия экономики, ИИ-журналист.
- **ВлодДоки** (docs.bln): документация по рантайму, эквайрингу, DNS, OAuth.
- **ВлодШкола** (school.edu.bln): интерактивные уроки («купи домен → настрой DNS → выпусти сертификат») с наградами и курсы.

## 11. Деньги и торговля

- **Эквайринг ВлодБанка**: платёжная страница `pay.bank.bln` (карта и PIN или QR), API-ключи, вебхуки с подписью, подписки, возвраты, комиссия банка (задаётся в админке), НДС с онлайн-продаж.
- **Вход для сайтов**: «Войти через ВлодПочту» (OAuth 2) и «Войти через ВлодУслуги» (с проверкой возраста по паспорту).
- **Интернет-магазин** на CMS списывает товар с общего склада Кассы. Заказ уходит на кухню или в сборку.
- **Доставка**: самовывоз по коду заказа; курьеры-игроки с подтверждением по QR; цифровые товары. Реальная (физическая) доставка — не чаще 1 раза в реальную неделю на покупателя и только после одобрения админа. Виртуальных доставок — без ограничений.

## 12. Конструктор и CMS

- Конструктор: готовые блоки (шапка, галерея, форма, товары) и правка HTML в любой момент. ИИ-генератор сайтов — за влодики, с дневным лимитом.
- CMS: блог, интернет-магазин, форум. Темы и плагины игроки продают с комиссией и НДС.

## 13. ИИ

Провайдер — Polza или DeAPI, бюджет до $5 в месяц, жёсткий счётчик расходов в админке: при достижении лимита ИИ отключается.
- ИИ-журналист.
- ИИ-ответы в поиске.
- Генератор сайтов.
- ИИ-жители: их число задаёт админ, у каждого кошелёк из эмиссии с лимитом. Действуют несколько раз за игровой месяц: покупают, пишут посты, ходят по сайтам. Всегда помечены как бот.

## 14. Безопасность, модерация, правила

- Взлом — часть игры: веб-уязвимости в коде игроков, DNS-атаки, социальная инженерия. Игрового DDoS нет.
- Госсайты не взламываются: это настоящий код платформы. Работает только bug bounty: за дыру в сайте платит владелец сайта, за дыру в госсайте — государство, за баг платформы — админ.
- Кражи влодиков: до этапа 8 разбирает админ, дальше полиция и суд.
- Реестр запрещённых сайтов по решению ведомства или суда. Провайдеры обязаны блокировать, показывается страница «Доступ ограничен». Обход через игровой VPN — легальная услуга лицензированных VPN-сервисов. Государство может блокировать конкретные VPN-узлы, поэтому идёт игра в кошки-мышки.
- Реально вредный контент: кнопка «пожаловаться админу» вне игры. Запрещено имитировать настоящие сервисы (Google, настоящие банки) и собирать настоящие пароли.
- Несовершеннолетние: азарт только 18+ по паспорту БФ. Незнакомцы не могут писать несовершеннолетним в личку, только друзья.
- Приватность: переписку и письма админ видит только по жалобе, с записью в журнал аудита.
- Правила БалНета — две части: игровые законы БФ и настоящие правила платформы. Черновик пишем мы, владелец правит.

## 17. Риски

- **VPS на 1–2 ГБ.** Pyodide и сотни сайтов на нём тесно. Меры: лимиты тарифов, пулы WASM-экземпляров, очередь. Если будет медленно — обсудим сервер мощнее.
- **Один домен.** Защита держится на sandbox без allow-same-origin и на shim. Любая ошибка в shim — дыра. Нужны отдельные тесты изоляции. Если окажется ненадёжно, переход на отдельный поддомен для контента игроков стоит недорого.
- **Объём.** Тринадцать больших этапов, срока нет. Порядок выше начинается с того, что владелец назвал первой очередью (Н1, Н2–Н4, Н6).
- **Несовершеннолетние и ИИ.** Ответы ИИ проходят фильтр, ИИ-жители не пишут несовершеннолетним в личку.
