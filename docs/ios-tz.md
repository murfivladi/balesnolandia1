# ТЗ: ВлодБраузер для iOS

Нативное приложение-браузер БалНета для iPhone и iPad. Основа — ответы владельца в `docs/ios-interview.md`.

> Игровой сервис. Не является банком, госорганом, платёжным средством или удостоверением личности.

## 1. Общее

| | |
| --- | --- |
| Название | ВлодБраузер |
| Устройства | iPhone, iPad (iOS 16+; на iOS 16 у профилей общий вход на госсайты — отдельное хранилище WebKit на профиль есть с iOS 17) |
| Язык | русский |
| Вид | как Chrome для iOS; тема по системе с ручным переключателем |
| Проект | `ios/VlodBrowser.swiftpm` — приложение Swift Playgrounds (SwiftUI + WKWebView); латиница в имени папки — чтобы не ломались git, zip и xcodebuild |
| Раздача | Swift Playgrounds на iPad (скачать на `https://bln.vladislavb.qzz.io/ios/`), позже TestFlight и скрытая страница App Store |
| Сервер | только `https://vps.vladislavb.qzz.io` (API) и `https://bln.vladislavb.qzz.io` (фронтенд госсайтов) |
| Сборка | GitHub Actions на macOS: сборка под симулятор iOS на каждый push в `ios/**` |

Приложение повторяет поведение веб-ВлодБраузера (`web/src/browser`), сеть по-прежнему считает API. Нового «интернета» в приложении нет: открываются только адреса БалНета.

## 2. Как открывается адрес

1. Ввод в адресной строке разбирается как в вебе (`shared/balnet-url.js`): схема → адрес; `bank.bln/cards` → `https://bank.bln/cards`; остальное — поиск во ВлодПоиске. `balnet://…` — внутренние страницы.
2. Устройство профиля (`client_id`) арендует IP у провайдера: `POST /api/net/lease`.
3. `POST /api/net/open { url, client_id, resolver?, jar?, referrer? }` — DNS → подключение → TLS. Ответ: `ok`, `code`, `ip`, `target`, `gov`, `dns`, `timing`, `tls`, `ticket`.
4. Для `https` приложение само проверяет сертификат (как `verifyTls` в `shared/balnet-pki.js`, на CryptoKit: ECDSA P-256 + SHA-256, канонический JSON, цепочка до корня из `GET /api/net/trust`, CT, OCSP). Ошибка → страница «Ваше подключение не защищено». Если https на сервере нет, приложение откатывается на http; для госсайтов (HSTS) так нельзя, им показывается ошибка.
5. Что показывается:
   - `target = app:<папка>` — госсайт: `https://bln.vladislavb.qzz.io/<папка>/#<путь>` в WKWebView; в адресной строке — `https://bank.bln/<путь>` (как `GovFrame` в вебе). Переходы внутри и в другие приложения переводятся обратно в адреса `*.bln`.
   - `target = site:…` и `ticket` — сайт игрока: `https://vps.vladislavb.qzz.io/api/net/web/<ticket><путь>` в WKWebView. Shim шлюза шлёт сообщения `parent.postMessage` — на верхнем уровне они приходят в то же окно; скрипт-мост в отдельном мире WebKit (`WKContentWorld`) пересылает их в приложение. Принимаются только адреса этого же сайта (`nav`), остальное — `open`, `jar`, `credential`, `notify`.
   - ошибка — страница ошибки с кодом Chrome (`NET_ERRORS`).
6. Изоляция: госсайты — в хранилище данных профиля (`WKWebsiteDataStore(forIdentifier:)`), cookies входа ВлодУслуг там; сайты игроков — в отдельном непостоянном хранилище и банк не видят. Их cookies и localStorage хранит приложение (jar по origin) и передаёт в `open`. Инкогнито — всё в памяти.

## 3. Этапы

### И1 — браузер, терминал, DevTools (первая версия)
- Проект `.swiftpm`, иконка, экран запуска, дисклеймер в «О ВлодБраузере».
- Первый запуск: выбор провайдера как договор (БалТелеком / ВлодЛинк / Балесно-Мобайл из `GET /api/net/providers`), DNS: провайдера / ВлодDNS 50.0.0.53 / свой.
- Вкладки: на iPhone — сетка карточек (свайп закрывает), на iPad — полоса вкладок сверху. Адресная строка сверху или снизу (настройка). Назад, вперёд, обновить, поделиться.
- Значок у адреса: «Госсайт БФ», замок, «Не защищено», «Опасный сайт».
- Новая вкладка: строка ВлодПоиска, госсайты, часто посещаемые.
- История, закладки, профили (у каждого свой `client_id`, IP, вкладки, cookies), инкогнито как в Chrome.
- Игровой статус-бар: провайдер и «сигнал» (время ответа VPS), IP БалНета по нажатию, игровая дата (`GET /api/clock`).
- Тема: система / светлая / тёмная, передаётся госсайтам (`data-theme`).
- Терминал `balnet://terminal` — нативный экран: `ipconfig`, `dig` (+trace, +short, +norec, +dnssec, +cd, -x), `nslookup`, `host`, `ping`, `traceroute`, `whois`, `curl`, `openssl s_client`, `ssh` с `nano`, история ↑↓, панель клавиш.
- DevTools (шторка): Network (как в вебе: статус, DNS-путь, TLS, тайминг), Консоль (`console.*` и ошибки страницы, ввод JS), Элементы (дерево DOM), Хранилище (cookies и localStorage сайта).
- Просмотр кода страницы (`view-source:`).
- Страницы ошибок, «БалНет на обслуживании» (пауза игрового времени).
- Сервер: `GET /api/app/ios` — последняя версия приложения и ссылка; в приложении баннер «Доступна новая версия».
- Сайт: страница `/ios/` с кнопкой «Скачать .swiftpm» и инструкцией; архив собирается при публикации фронтенда.
- CI: сборка под симулятор iOS на macOS.

### И2 — аккаунт, пароли, Face ID, новая вкладка
- Аккаунт ВлодБраузера и синхронизация (протокол Н8.2: PBKDF2 + AES-GCM на устройстве, на сервере только шифротекст): закладки, история, открытые вкладки, пароли, настройки — общие с веб-версией.
- Менеджер паролей: Keychain под Face ID, предложение сохранить (сообщение `credential` shim и формы госсайтов), подстановка.
- Face ID: при открытии `bank.bln`, перед переводом/оплатой, вместо PIN карты (нужен мост госсайт ↔ приложение: `window.__balnetNative`).
- Приватность банка: размытие при сворачивании, предупреждение о скриншоте.
- Загрузки: «Поделиться», Фото, Файлы, экран «Скачанные».
- Импорт из веб-ВлодБраузера: QR и файл JSON.
- Безопасный просмотр (`shared/balnet-safe.js`), подсказки в адресной строке (ВлодПоиск, история, закладки), реклама на новой вкладке, лента БалНовостей, обои.
- Мини-игра на странице «нет связи».
- Отчёты о сбоях на VPS (`POST /api/app/crash`, раздел в админке).

### И3 — нативные функции
- QR-сканер: оплата по QR, проверка паспорта/чека/документа, адреса сайтов, штрихкоды для Кассы.
- Кошелёк: карты ВлодБанка с QR и штрихкодом для кассы.
- Уведомления: переводы и оплаты, квитанции/счета/долги, заявления/домены/хостинг — через WebSocket, пока приложение запущено; Web Push сайтов — один API для iOS и веба (`push.bln`).
- Вибрация и звуки, быстрые действия с иконки, ссылки `bln://`, Siri и Команды («Открой банк», «Переведи…» с подтверждением).

### И4 — Касса на iPad, сайтостроители, дети
- Режимы: касса во весь экран, терминал покупателя, киоск и табло очереди (подсказка «Гид-доступ»); печать чека через AirPrint и «Поделиться».
- SSH-клиент и редактор файлов хостинга с подсветкой.
- Детский профиль: часы в день и «не позже», снятие по PIN родителя.

### И5 — тарифы связи и публикация
- Сервер: тарифы провайдеров с абонплатой за игровой месяц (автоплатёж), провайдеры-игроки с лицензией (как хостеры), раздел в админке; в статус-баре — тариф и трафик.
- TestFlight, скрытая страница App Store, настоящие пуши APNs.
- Расширения браузера — отдельно, позже.

## 4. Ограничения Swift Playgrounds
- На iPhone Swift Playgrounds нет: iPhone — после покупки Apple Developer (TestFlight).
- Нет виджетов и расширений приложения, нет APNs. Face ID, камера, App Intents и URL-схема — через свойства приложения в `Package.swift`, проверяются на устройстве.
- Сборку проверяет CI; ошибки на iPad присылаются скриншотом.
